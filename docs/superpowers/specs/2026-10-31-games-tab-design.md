# Вкладка «Игры»: соло и сетевой режим без сервера

## Зачем
Вкладка «Игры» выключена (`Menu(VOMenuType.GAMES, false)` в `GetMenuItemsUseCase.kt`). Нужно её включить, починить существующие игры и сделать так, чтобы у каждой игры было два режима: соло, и вдвоём по сети (против друг друга или кооператив). Таблица рекордов синхронизируется между всеми, у кого включено соединение.

## Цели
- Вкладка включена, три существующие игры (Угадай спелл, Kill Creep, крестики-нолики) запускаются.
- Единый каркас: игра = правила + режим (`Solo`, `Versus`, `Coop`). Правила не зависят от транспорта.
- Транспорт: Wi-Fi Direct (основной), websocket в одной Wi-Fi сети (запасной). Оба уже есть в `feature/games/xo/domain`.
- Таблица рекордов: локальная (Room), живая синхронизация с подключёнными участниками.

## Не цели / антицели
- Никакого центрального сервера и интернет-матчмейкинга.
- Нет единой глобальной таблицы: она общая только для тех, кого устройство встречало по сети.
- Защиты от подделки результатов нет (игра между друзьями).
- Не переписываем транспорты Wi-Fi Direct и websocket, они работают.

## Дизайн
**Каркас.** Сетевой слой (`SocketMessenger`, `ServerCreator`, `ClientCreator`, discovery use cases) выносится из `xo` в общий модуль игр. `xo` переезжает на него.

**Комната.** Один телефон хост (group owner или websocket-сервер): раздаёт одинаковые раунды (один и тот же вопрос, одна и та же волна крипов), собирает ответы, считает, кто быстрее, рассылает состояние. Solo полностью локальный.

**Рекорды.** Запись: игрок + игра + лучший результат + время. При подключении участники обмениваются записями и сливают их (максимум по паре игрок+игра). Новый рекорд пушится всем подключённым сразу. Записи встреченных игроков сохраняются; онлайн-статус отмечается значком.

**Игры** (на данных приложения: герои, предметы, спеллы, реплики):
| Игра | Solo | Versus / Coop |
|---|---|---|
| Угадай спелл (есть) | серия верных, рекорд | Versus: одни вопросы, кто быстрее. Coop: общие жизни и счётчик |
| Угадай героя по силуэту/реплике | то же | то же |
| Собери предмет по рецепту | на время | Versus: кто первым. Coop: у каждого своя половина |
| Kill Creep (есть) | очки за добивания | Versus: одна волна, больше ластхитов. Coop: делят две линии |
| Больше или меньше (HP, цена, урон) | серия | Versus: гонка |
| Крестики-нолики (есть) | против бота | Versus на общем каркасе |

## Порядок
1. Включить вкладку, проверить три игры.
2. Вынести сетевой слой, комната, протокол.
3. Таблица рекордов и синхронизация.
4. Угадай спелл в трёх режимах.
5. Угадай героя.
6. Остальные игры.

## Проверка
- Wi-Fi Direct на эмуляторе не работает, проверяется только на реальных телефонах.
- Websocket-путь проверяется на эмуляторе вместе с реальным телефоном в одной Wi-Fi сети (эмулятору нужен мост/проброс портов, детали на builder'е).

## Решения за builder'ом (мои допущения)
- Формат сообщений протокола и сериализация.
- Идентификатор игрока: имя устройства (`GetDeviceNameUseCase`) плюс случайный id, сохранённый локально.
- Схема Room для таблицы рекордов.
